# Add to home screen

Put Delivery Tracker on your phone's home screen so it opens like a normal app, full screen, with one tap. You only do this once.

First open **[delivery-tracker-fawn.vercel.app](https://delivery-tracker-fawn.vercel.app)** on the phone.

## iPhone

Use **Safari** (the blue compass icon).

### 1. Tap ••• then Share

<img src="./img/install-iphone-share.webp" alt="iPhone Safari menu: Share" width="300">

<div class="callouts">

- <span class="n">1</span> Tap **•••** at the bottom right, then tap **Share**. On older iPhones, **Share** (the square with an arrow pointing up) is right in the bottom bar.

</div>

### 2. Tap Add to Home Screen

<img src="./img/install-iphone-add.webp" alt="iPhone share sheet: Add to Home Screen" width="300">

<div class="callouts">

- <span class="n">1</span> Tap **Add to Home Screen**. If you don't see it, tap **View More** first, then scroll down.

</div>

### 3. Tap Add

<img src="./img/install-iphone-confirm.webp" alt="iPhone: Add to Home Screen, Add button" width="300">

<div class="callouts">

- <span class="n">1</span> Leave the name and **Open as Web App** as they are, and tap **Add** at the top right.

</div>

## Android

Use **Chrome**.

### 1. Tap Install app

<img src="./img/install-android-menu.webp" alt="Android Chrome menu: Install app" width="300">

<div class="callouts">

- <span class="n">1</span> Tap **⋮** at the top right of Chrome, then tap **Install app**. On some phones it says **Add to Home screen**.

</div>

### 2. Tap Install

<img src="./img/install-android-add.webp" alt="Android: Install app popup" width="300">

<div class="callouts">

- <span class="n">1</span> Tap **Install**.

</div>

### 3. Tap Add automatically

<img src="./img/install-android-confirm.webp" alt="Android: Add to Home screen, Add automatically" width="300">

<div class="callouts">

- <span class="n">1</span> Tap **Add automatically**. The icon goes on your home screen by itself. Some phones skip this step.

</div>

## Done

Go to your home screen and tap the **KH Delivery** icon. You sign in the first time, then it remembers you. See [Signing in](./sign-in).
